# Skills and provenance

The private research notes establish tool use, but do not provide a verified, publishable inventory of named Codex skill packages and corresponding upstream sources. No named skill package is credited here without that evidence.

Codex, Playwright, Ollama and REA are documented as tools in [tooling](tooling.md); tool use does not by itself prove invocation of a particular skill. Private research instructions and local orchestration policies are excluded. Shared repository guidance is tracked in [AGENTS.md](../AGENTS.md).

Documentation organization follows a GitHub documentation guide retained outside this repository. Public platform references are listed in [references](references.md).

# Skills and provenance

The private research notes establish tool use, but do not provide a verified, publishable inventory of named Codex skill packages and their upstream sources. No named skill package is credited here without that evidence.

Codex, Playwright, Ollama and REA are documented as tools in [tooling](tooling.md); tool use does not by itself prove invocation of a particular skill. Private instructions and local orchestration policies are excluded.

This repository's documentation was organized using an owner-provided GitHub documentation guide. Its reusable private text is not copied into the publication tree. Public platform references are listed in [references](references.md).

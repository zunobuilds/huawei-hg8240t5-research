# Image provenance

Two owner-created single-frame photographs of the PCB backside are included. These public copies retain their original JPEG encoded image data; EXIF/XMP/IPTC and other removable metadata were stripped. Originals remain private and unchanged.

| File | Contents | Limitation |
| --- | --- | --- |
| [Connector region](pcb/pcb-connector-side.jpg) | Connector housings, solder joints and backside components | Partial board view; glare |
| [Trace detail](pcb/pcb-trace-detail.jpg) | Backside traces, solder joints and footprints | Soft focus limits fine marking interpretation |

Frames were visually selected to exclude the board's identifying serial/QR sticker. No generative editing, sharpening, component reconstruction or signal annotation was applied. Original capture orientation is retained.

Public file hashes are in [SHA256SUMS](SHA256SUMS). The full mosaic, raw frame collection and identifying overview are excluded. Component identifications rely on the broader private research, not these two photographs alone.

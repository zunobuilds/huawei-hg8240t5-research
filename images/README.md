# Image provenance

Four image assets are included: an exterior view, two PCB backside details and a component-side composite. Originals remain private and unchanged. EXIF/XMP/IPTC and other removable metadata were stripped from the included copies.

| File | Contents | Limitation |
| --- | --- | --- |
| [Component-side composite](pcb/pcb-component-side.jpg) | Bottom-facing PCB side with connectors and components | Reduced multi-view composite; source blur, seams and parallax can remain |
| [Exterior view](device/hg8240t5-exterior.jpg) | Enclosure, vented top and Singtel branding | Cropped and colour-adjusted photograph; perspective and depth of field limit measurements |
| [Connector region](pcb/pcb-connector-side.jpg) | Connector housings, solder joints and backside components | Partial board view; glare |
| [Trace detail](pcb/pcb-trace-detail.jpg) | Backside traces, solder joints and footprints | Soft focus limits fine marking interpretation |

The exterior image was selected from the enclosure photo set, cropped and given gentle tone and colour adjustments in GIMP. It is a 1,800 × 1,128 pixel export from the camera JPEG, with no generative editing or reconstructed detail.

The PCB frames were visually selected to exclude the board's identifying serial/QR sticker. The two PCB copies retain the original JPEG encoded image data and capture orientation. No sharpening, component reconstruction or signal annotation was applied.

Public file hashes are in [SHA256SUMS](SHA256SUMS). The full mosaic, raw frame collection and identifying overview are excluded. Component identifications rely on the broader private research, not these photographs alone.

The small [AI-assisted label](ai-assisted.svg) beneath the README title is project-created SVG text artwork. It discloses AI assistance; it is not a device photograph, certification or external service badge.

The component-side image is a reduced export from a 1,297-photo workflow with guarded projective registration, local focus selection and reviewed regional composition. The lossless master remains local. No AI-generated detail, inpainting or arbitrary post-render enlargement was applied.
